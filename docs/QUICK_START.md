# Quick Start Guide

Get playing in 5 minutes!

## 1. Prerequisites ✓

- [x] MATLAB R2016b or later
- [x] Image Processing Toolbox (check in MATLAB: `ver('images')`)

Don't have it? [Full Setup Guide](docs/SETUP_GUIDE.md)

## 2. Clone Repository

```bash
git clone https://github.com/yourusername/Energy-Game-Clean-vs-Unclean.git
cd Energy-Game-Clean-vs-Unclean
```

Or [Download as ZIP](https://github.com/yourusername/Energy-Game-Clean-vs-Unclean/archive/refs/heads/main.zip)

## 3. Launch Game

**In MATLAB:**

```matlab
cd Energy-Game-Clean-vs-Unclean
addpath(genpath(pwd))
Final_SDP_Game_By_Mcelhaney_Yang_WithComments
```

**That's it!** 

## 4. Play

- **Menu**: Click "Start" to begin
- **Quiz**: Answer questions about energy and environment
- **Puzzle**: Use WASD to push soap and clean up spills
- **Goal**: Complete all 3 chapters and achieve a clean energy future!

## Controls Cheat Sheet

| Key | Action |
|-----|--------|
| **W** | Move up |
| **A** | Move left |
| **S** | Move down |
| **D** | Move right |
| **Mouse** | Click menu/answer buttons |

## Game Chapters

### Chapter 1: Coal 
- Learn how coal forms
- Understand environmental impact (acid rain, CO₂)
- Clean up industrial spills

### Chapter 2: Petroleum 
- Discover petroleum uses
- Explore environmental consequences (greenhouse gases)
- Clean an oil rig spill

### Chapter 3: Wind Energy 
- Learn how wind turbines work
- Evaluate renewable energy tradeoffs
- Final cleanup challenge

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Game won't start | [Setup Guide](docs/SETUP_GUIDE.md) → Troubleshooting |
| Sprites not showing | Re-download, check `assets/sprites/` folder |
| Input not working | Click game window to focus, restart MATLAB |
| MATLAB complains about missing files | Run `addpath(genpath(pwd))` |
