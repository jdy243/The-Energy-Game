🚀 最快发布方式（5 分钟）
──────────────────────────

第 1 步：准备项目（2 分钟）
  1. 打开你的 Energy Game 项目目录
  2. 复制这些文件到你的项目中：
     README.md, LICENSE, CONTRIBUTING.md, .gitignore
  3. 在你的项目目录中打开终端/命令提示符
  4. 运行：
     git init
     git add .
     git commit -m "Initial commit"

第 2 步：创建 GitHub 仓库（2 分钟）
  1. 访问 github.com (需要账户，免费)
  2. 点击 "New repository"
  3. 名称：energy-game
  4. 点击 "Create repository"
  5. 复制显示的 URL

第 3 步：上传代码（1 分钟）
  在终端运行（替换你的用户名）：
  git remote add origin https://github.com/YOUR-USERNAME/energy-game.git
  git branch -M main
  git push -u origin main

完成！🎉
